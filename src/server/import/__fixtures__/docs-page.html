Create a ticket

Creates a new support ticket. POST https://api.example.com/v2/tickets

curl -X POST https://api.example.com/v2/tickets \
  -u API_KEY:x

Body parameters

NameTypeRequiredDescription
subjectstringYesThe ticket subject
priorityintegerNo1 (low) to 4 (urgent)
  • Returns 201 with the ticket.
